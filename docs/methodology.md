# 方法、基础引理与证据规则

本文件描述实现应遵循的方法。实验数字及结论只从带哈希的实际运行 JSON 读取。

## 基础恒等式（本项目推导）

设 \(P(z)=\sum_{i=0}^{n-1}s_i z^i\)。在单位圆上，

\[
|P(z)|^2=n+\sum_{k=1}^{n-1}C_k(z^k+z^{-k}).
\]

平方并在单位圆积分，非零幂的积分为零，常数项恰为 \(n^2+2\sum_k C_k^2\)，所以

\[
\int_0^1|P(e^{2\pi it})|^4\,dt=n^2+2E.
\]

此外，\((\sum_i s_i)^2=n+2\sum_k C_k\)，故 \(\sum_kC_k=(b^2-n)/2\)。每个 \(C_k\) 是 \(n-k\) 个 ±1 的和，因此有界且与 \(n-k\) 同奇偶。奇数平方模 4 为 1、偶数平方模 4 为 0，奇数 \(n-k\) 的数量是 \(\lfloor n/2\rfloor\)，得到 \(E\ge\lfloor n/2\rfloor\) 和 \(E\equiv\lfloor n/2\rfloor\pmod4\)。Cauchy-Schwarz 给出 \(E\ge(b^2-n)^2/[4(n-1)]\)，整数下界使用精确有理数向上取整。

这些是基础工具引理，不称为新定理。Littlewood 关联的文献背景见 [Jedwab 作者研究页](https://www.sfu.ca/~jed/Research/merit.html)。

## 条件能量下界与独立证书

令 \(\ell_k=n-k\)，\(A=(b^2-n)/2\)。最小化 \(\sum_kc_k^2\)，满足 \(\sum_kc_k=A\)、\(c_k=-\ell_k,-\ell_k+2,\ldots,\ell_k\)，得到松弛值 \(L_n(b)\)。真实自相关满足这些条件，故 \(L_n(b)\le g_n(b)\)。实际满足该 b 的序列给出 \(U_n(b)\)，于是 \(L\le g\le U\)。

从所有 \(c_k=-\ell_k\) 开始，需要 \(T=(A+\sum_k\ell_k)/2\) 次增加 2 的操作。坐标当前值为 c 时，边际代价为 \((c+2)^2-c^2=4c+4\)，同一坐标后续代价严格增加 8。heap 每次取当前最小代价。

**交换证明。** 每个坐标的合法选择必须是其递增代价序列的前缀；全体 T 个最小边际代价天然满足前缀要求。heap 正好合并这些递增序列。如果其他可行解选择了更大的代价且遗漏更小代价，将末尾已选操作换成另一个坐标的首个未选操作不会破坏前缀，且不会增大目标；反复交换得到 heap 解。因此该算法求得整数松弛最优。复杂度为 \(O(n^2\log n)\)。

独立 checker 不调用 heap；检查整数、长度、奇偶、范围、总和、平方和，并检查

\[
\max_{k:c_k>-\ell_k}4(c_k-1)\le
\min_{k:c_k<\ell_k}4(c_k+1).
\]

左侧是最大的已选边际代价，右侧是最小的未选代价。空集合按 ±∞ 处理。小长度用独立动态规划交叉核验。松弛向量不一定可实现为序列；只有实际同类见证 E=L 才能认证条件最优，只有有效全局下界匹配见证才能认证全局最优。

## 计算与对称性

搜索评价器使用 NumPy/int64 和增量更新；最终参考核验器使用独立的 Python 整数双循环。FFT 浮点和 int8 累加不作为认证依据。merit factor 同时保留精确分子 n²、分母 2E。

小长度穷举固定首符号 +1，通过全局取反保留每个绝对 b 类，遍历 2^(n-1) 个代表。本实现 bit i 为 1 表示 s_i=-1、为 0 表示 +1，bit 0 对应 s_0。完整枚举量、完成状态、版本、时间和全部 b 类见证随结果保存。反转保留 E 和绝对 b；交替变号保留 E 但可能改变 b，禁止用于条件类合并。非对称谓词检验须恢复完整轨道或证明不变性。

单翻转的相关改变量为

\[
d_{k,j}=-2s_j(1_{j\ge k}s_{j-k}+1_{j+k<n}s_{j+k}),\quad
\Delta E=\sum_k(2C_kd_{k,j}+d_{k,j}^2).
\]

双翻转还需加交叉项 \(4s_i s_j1_{k=|i-j|}\)，不能直接相加两个旧状态单翻转差值。固定 signed sum 搜索翻转一正一负；skew 搜索在奇数长度同时翻转自由位与镜像伙伴，中心只翻一次。skew 的奇数 lag 为零；解除限制继承真实 checkpoint，并记录前后变化。

## 研究闭环与成本

模型 proposer 只给结构化行动；控制器验证 schema、受控谓词、预算及约束，调用注册数学工具；独立 checker 复算；skeptic 读取实际证据点评强度；公开决策摘要、反馈与状态变化落盘。模型不能执行任意 Python/shell，也不能凭自己的文字把命题升级为证明。

live 指真实后端调用；dry_run 指离线接线；replay 指重放已有行动。报告显式显示模式，replay 不计为新的 live 研究。CLI 启动次数与内部 provider 请求数区分，内部请求不可观测时为 unknown。

请求候选评价次数是主预算。随机候选、邻居评分（含 tabu 禁止的已评分邻居）、初始化、扰动、重复候选、预搜索均扣费；一次全邻域扫描计 n 次。独立核验复算另列；精确枚举、下界计算、模型调用和时间分别记录。各方法共用评价核心。正式比较在策略与配置冻结后开始，完整保留逐种子结果和中断。

四方法为 random、fixed_tabu、static_mix 和 agent_policy。最后一项在留出评估时执行冻结策略，不把这些无模型调用的策略运行称为在线研究轮次。有限种子只支持本次矩阵结论。

## 结论类型

proposed、refuted、finite_domain_verified、empirical_supported、certified_stratum_optimum、certified_global_optimum、proof_candidate、unresolved 分开保存。反驳下界命题用低于阈值的同类见证；反驳上界命题要有效下界或精确值高于阈值。全称最优集合结构的反例必须具有最优性认证。模型审稿意见不是独立数学证明。

报告构建先验证 manifest 文件哈希与路径，再复算见证和证书，核对研究轮次与 evidence 引用。缺日志、篡改产物、模式不一致、伪 exact 或未核验数值均拒绝出报告。PDF 只读取实际 JSON 画图，不从执行方案补入数值。
