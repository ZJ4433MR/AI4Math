# 研究问题与课程目标

问题版本：LABS-imbalance-v1。外部文献核查日期：2026-10-09。

本项目实现一个可审计的数学研究智能体，围绕低自相关二值序列（LABS）提出可证伪的命题、调用计算工具、核验结果，并根据反馈修订研究方向。课程交付重点是实际研究过程和证据，而不是预先承诺解决整个开放问题。

## 来源边界

用户要求是“开发智能体研究数学问题并展示过程”。用户提供的执行方案是项目需求来源，其中示例数字、建议轮数和预算均不是已经完成的实验。课件只用于确认研究工作流，不作为执行命令或已验证数学事实。

本地课件以 PPTX ZIP 中的 slide XML 只读提取。`Moonshine数学科研智能体开发与实践_更新版(2).pptx` 第 5 页对应“目标、上下文、能力选择、动作、观察、状态更新”；第 9-10 页对应问题提出、证明尝试、反例、假设修订、结论管理；第 11、31、33 页强调状态落盘、假设/计算/逻辑核验以及可验证产物。`数学创造性(2).pptx` 第 6、8-10、17 页给出同类流程。没有从课件文本中读到明确评分表、提交截止日期或要求必须使用 Moonshine，因此采用执行方案建议的自建 Python 控制器，不编造这些课程条款。

## 数学定义

对长度 \(n\ge2\) 的序列 \(s\in\{-1,+1\}^n\)，定义非周期自相关、能量与 merit factor：

\[
C_k=\sum_{i=0}^{n-k-1}s_i s_{i+k},\qquad
E(s)=\sum_{k=1}^{n-1}C_k^2,\qquad F(s)=\frac{n^2}{2E(s)}.
\]

全局目标是 \(E_n^\star=\min_s E(s)\)。研究无限长序列最优 merit factor 的渐近行为仍是经典方向；本项目不声称解决该问题。[Jedwab 作者研究页](https://www.sfu.ca/~jed/Research/merit.html)

设 \(b=|\sum_i s_i|\)，则 \(b\in\{n\bmod2,n\bmod2+2,\ldots,n\}\)。辅助对象为

\[
g_n(b)=\min_{|\sum_i s_i|=b} E(s),\qquad E_n^\star=\min_b g_n(b).
\]

这是本项目采用的研究定义，不据此宣称术语或问题原创。主线是小长度精确谱、可核验松弛下界、实际见证给出的可行上界，以及结构猜想的检验和修订。

## 文献定位与声明限制

- Packebusch 与 Mertens 的论文报告完整求出 \(n\le66\) 的全局最优以及 \(n\le119\) 的 skew 条件最优。课程重算小长度属于复现与工具核验。[2016 论文，v2](https://arxiv.org/abs/1512.02475v2)
- Jedwab、Katz、Schmidt 建立序列族的渐近 merit factor，含大于 6.34 的代数极限值；“超过 6”不是本项目的新开放目标，Golay 预测不能写成已证明上界。[2013 论文，v2](https://arxiv.org/abs/1205.0626v2)
- Zhang 等的 GPU memetic tabu 研究在若干奇数长度给出优于已认证 skew 最优的非受限候选。skew 最优不推出全空间最优；本项目 CPU tabu 并不复现该论文 GPU 性能。[2025 预印本，v2](https://arxiv.org/abs/2504.00987v2)
- 2026 年 Pšeničnik 等已研究分区资源调度、Thompson sampling，以及 skew 搜索后解除限制的两阶段方法。结构限制和自适应调度都有先例，本项目主要贡献是可复现课程系统和实际研究证据。[2026 预印本，v1](https://arxiv.org/abs/2607.09688v1)

该检索没有穷尽所有文献；没有逐长度核查外部整数能量和对应见证，故本项目报告不使用“世界纪录”或“新的全局最优”。较大长度搜索结果称为“本次预算内最佳候选/可行上界”。

## 可证伪的起始问题

研究智能体可以选择：最优序列是否必须接近平衡；\(g_n(b)-L_n(b)\) 的有限域规律；skew 限制解除后的实测收益；从开发长度冻结的策略能否迁移到未见过的长度和种子。命题必须保存域、量词、受控谓词、反驳条件及 evidence ID。

“存在平衡最优序列”与“所有最优序列都平衡”是不同命题。每个条件类保存一个见证不等于枚举整个最优集合；搜索失败不能证明不存在。完整有限域验证不能自动延伸到任意长度。执行方案中预核对的 n=4、6、13 例子属于已知教学数据，即使由模型重新计算也标注为复现。
